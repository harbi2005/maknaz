# الهوية البصرية

| المجلد | المحتوى |
|---|---|
| `identity/MAKNAZ_identity_board.png` | لوحة الهوية الأصلية |
| `logo/` | `logo_icon.png` الرمز السداسي · `logo_wordmark_light.png` و`logo_wordmark_dark.png` الكلمة · `logo_lockup_on_dark.png` الشعار الكامل على الداكن |
| `fonts/` | IBM Plex Sans Arabic · IBM Plex Sans · IBM Plex Mono · Tajawal — كل مجلد مع ملف `OFL.txt` |

## القواعد

- الشعار يُستخدم كما هو: لا إعادة رسم، ولا تغيير نسب أو ألوان، ولا تأثيرات.
- الشعار: «HIDDEN RESOURCES. NEW VALUE.»
- الألوان: انظر [design-tokens](../packages/design-tokens/README.md) والقرار المفتوح OD-13 حول تعارض القيم.
- الخطوط بترخيص **SIL Open Font License 1.1**: مسموح التضمين والتوزيع مع إرفاق الترخيص، وممنوع بيع الخط منفردًا.

## الأصول الكبيرة

الفيلم التعريفي وملفات الفيديو **لا تُحفظ في Git** (أحجام كبيرة). تُولد بأداة [`tools/brand-film`](../tools/brand-film/README.md) وتُنشر عبر GitHub Releases بعد الموافقة.
