## تعارضات معروفة مع القرارات المعتمدة

الملفان التعريفيان بُنيا على [موجّه الملف التعريفي](../sources/02_project_file_brief_2026-11-02.txt) قبل اعتماد القرارات الهندسية الأخيرة، لذلك يتبعان صياغات تخالف المعتمد الآن:

| البند | الصياغة في الموجّه السابق | المعتمد الآن |
|---|---|---|
| إعادة جدولة الشحن | «إعادة الجدولة بموافقة الأطراف المعنية» | **المنجم وحده** يمدد (حد 2 × 72 ساعة) دون موافقة المصنع، مع إعادة تأكيد الناقل — [SHIPMENT_EXTENSIONS](../04-domain/SHIPMENT_EXTENSIONS.md) |
| الدفع | «تُستكمل إجراءات الدفع إذا كانت الخدمة مفعلة» | دفع **محاكى إلزامي** بعد التأكيد الثلاثي بمهلة 24 ساعة — [PAYMENT_SIMULATION](../04-domain/PAYMENT_SIMULATION.md) |
| الإلغاء بعد الدفع | «لا تفترض الإلغاء التلقائي بعد الدفع…» | إلغاء تلقائي معتمد عند تجاوز موعد الاستلام + ساعتين مع استرجاع محاكٍ كامل، ولا إلغاء بعد `PICKED_UP` — [CANCELLATION_RULES](../04-domain/CANCELLATION_RULES.md) |
| ألوان الهوية | قيم HEX مختلفة بين لوحة الهوية والموجّه | قرار مفتوح OD-13 |

**القرار:** لا تُعدل نسخة سبق إرسالها لجهة خارجية (مثل ملف الهاكثون). أي نسخة جديدة تُولد من الأداة بعد التصحيح وتحمل رقم إصدار جديد.

## إعادة التوليد

```bash
python3 tools/docs-pdf/build_docs.py          # يكتب في tools/docs-pdf/out/
cp tools/docs-pdf/out/MAKNAZ_Engineering_Docs_AR.pdf docs/exports/
```

تتطلب Playwright (Chromium) و`mmdc` وpypdf وPillow وmarkdown — التفاصيل في [tools/README.md](../../tools/README.md).
