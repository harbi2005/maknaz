# الفاتورة المحاكاة

[← فهرس الوثائق](../README.md)

> الفاتورة في النسخة الأولى **مستند تنظيمي محاكى، وليست فاتورة ضريبية**، ولا تُحتسب فيها ضريبة (OD-12). القواعد: BR-040، BR-045، BR-078؛ حالة الاستخدام UC-012.

## 1. متى تُنشأ

تلقائيًا وذريًا **ضمن معاملة التأكيد الثلاثي** (اختيار المصنع لعرض نقل صالح). فاتورة واحدة لكل صفقة (قيد فريد). فشل إنشائها يلغي معاملة التأكيد كاملة.

## 2. الحقول

| الحقل | المصدر |
|---|---|
| المرجع `MKZ-INV-YYYY-NNNNNN` | مولد |
| الصفقة | `deal_id` |
| المشتري، المنجم، الناقل | لقطة بيانات الجهات وقت الإصدار |
| المادة، الكمية، سعر الوحدة | لقطة الصفقة التجارية |
| إجمالي المادة | `round(quantity × unit_price)` بالهللة |
| النقل | `transport_total_halalas` من لقطة العرض المختار |
| الرسوم الإضافية | البنود المشمولة في العرض |
| الإجمالي النهائي | مجموع البنود (قيد CHECK) |
| التاريخ | `issued_at` (UTC، يُعرض بتوقيت الرياض) |
| مهلة الدفع | `issued_at + 24h` |
| حالة الدفع | انظر [PAYMENT_SIMULATION.md](PAYMENT_SIMULATION.md#3-الحالات) |
| الوسم | `DEMO / SIMULATION — ليست فاتورة ضريبية` (ظاهر دائمًا) |

## 3. البنود (`invoice_items`)

| النوع | مثال (افتراضي) |
|---|---|
| `MATERIAL` | 600 طن × 42.00 = 25,200.00 |
| `TRANSPORT` | 21,600.00 |
| `LOADING` / `UNLOADING` / `HANDLING` | إن لم تكن مشمولة في سعر النقل |
| `ADJUSTMENT` | فرق سعر إعادة الإسناد (موجب أو سالب) |

## 4. عدم القابلية للتعديل

اللقطة والمبالغ لا تُعدل بعد الإنشاء (طبقة الخدمة + trigger). أي تغيير لاحق = بند `ADJUSTMENT` جديد مرتبط بسببه.

## 5. العرض والتنزيل

- الأطراف الثلاثة والإدارة فقط (P-50، P-51)؛ غير الطرف ← `404`.
- PDF بخط عربي مضمن، ووسم المحاكاة في الرأس والتذييل.
- المستندات التنظيمية الأخرى للصفقة: تأكيد الطلب، عرض النقل المعتمد، إثبات التحميل، إثبات التسليم.

## 6. الاختبارات

TS-085، TS-086، TS-098.
