# متطلبات البيانات

[← فهرس الوثائق](../README.md)

> تحدد البيانات التي تحتاجها المنصة للتشغيل والعرض التجريبي، وقواعد جودتها، والفصل بين الحقيقي والمحاكى. المالك: لمى العمير (DA-001 – DA-014). المخطط التفصيلي: [DATABASE_DESIGN.md](../03-architecture/DATABASE_DESIGN.md). القوالب: [data/templates/](../../data/templates/).

## 1. تصنيف البيانات

| الفئة | الوصف | المكان | الوسم الإلزامي |
|---|---|---|---|
| **مرجعية موثقة** | مؤشرات رسمية منشورة | `data/reference/` | الجهة، الرابط، تاريخ النشر والاطلاع |
| **مرجعية تشغيلية** | فئات المواد، أصناف الحمولة، أنماط النقل، فئات المركبات، المناطق الإدارية | بذرة قاعدة البيانات | — |
| **تجريبية (محاكاة)** | مناجم ومصانع وناقلون ومواد وأسعار وهمية للعرض والاختبار | `data/demo/` (عند إنشائها) | `is_demo = true` + أسماء وهمية واضحة |
| **تشغيلية حقيقية** | ما يدخله المستخدمون بعد الإطلاق | قاعدة البيانات فقط | لا تُحفظ في المستودع |

**قاعدة صارمة:** لا تُخزن بيانات تشغيلية حقيقية أو بيانات شخصية في المستودع.

## 2. مجموعات البيانات المطلوبة للعرض التجريبي

| المجموعة | القالب | الحقول الأساسية | التغطية المطلوبة |
|---|---|---|---|
| فئات المواد | `material_categories.csv` | code, name_ar, name_en, cargo_class | 4–6 فئات عامة (خبث، مخلفات معالجة، صخور مزاحة، ناعم محاجر…) |
| المناجم | `mines.csv` | demo_id, org_demo_id, name, primary_activity, region_code, lat, lng | 3–5 مناجم في منطقتين على الأقل |
| المواد | `material_listings.csv` | demo_id, mine_demo_id, category_code, title, physical_state, total_quantity_tons, asking_price_halalas, loading_conditions | 6–10 مواد بأسعار افتراضية |
| المواصفات | `material_specifications.csv` | listing_demo_id, property_name, value, unit, verification_status, document_demo_id | كل وسوم التحقق الأربعة، بما فيها `UNKNOWN` |
| مواقع المصانع | `factory_sites.csv` | demo_id, org_demo_id, name, region_code, lat, lng | 3–4 مصانع |
| المواقع التشغيلية للناقلين | `carrier_operating_locations.csv` | demo_id, org_demo_id, location_kind, region_code, lat, lng | تغطية نطاقات B1–B4 |
| خدمات الناقلين | `carrier_services.csv` | demo_id, org_demo_id, mode_code, vehicle_type_code, supported_cargo_classes, payload_tons_per_vehicle, min/max_shipment_tons | ناقل واحد على الأقل غير متوافق مع صنف الحمولة |
| قواعد التسعير | `carrier_pricing_rule_versions.csv` | service_demo_id, pricing_model, المعاملات، الرسوم، minimum_charge_halalas | النماذج الأربعة |
| حالات التسعير المرجعية | `pricing_reference_cases.csv` | case_id, المدخلات، expected_total_halalas | تغطي TS-070–076 |

## 3. معايير الجودة

| البند | المعيار |
|---|---|
| الوحدات | الكمية بالطن (3 خانات)، المال بالهللة (عدد صحيح)، المسافة بالكم، الوقت ISO 8601 UTC |
| الإحداثيات | ضمن المملكة؛ 6 خانات عشرية؛ لا إحداثيات لمواقع حقيقية لشركات قائمة |
| المفاتيح | كل `*_demo_id` فريد؛ صفر مفاتيح يتيمة |
| القيم المسموحة | مطابقة لقيود CHECK في قاعدة البيانات |
| المواصفات | `LAB_REPORTED` تشير إلى وثيقة تجريبية موسومة؛ `UNKNOWN` بلا قيمة |
| الأسماء | وهمية بوضوح («منجم تجريبي أ»، «ناقل تجريبي 2») |
| التوثيق | سجل افتراضات لكل مجموعة: كيف اختيرت القيم وحدود دقتها |
| التحقق | تمر بقيود قاعدة البيانات عند التحميل (`load_demo_data`) دون أخطاء |

## 4. ما لا تتضمنه البيانات

- لا أسماء أو مواقع أو أسعار لشركات حقيقية.
- لا ادعاء بصلاحية أي مادة لصناعة محددة؛ المواصفات التجريبية للعرض فقط.
- لا تقارير مختبر حقيقية؛ الوثائق التجريبية موسومة «نموذج للعرض».

| من | إلى | الصيغة | الشرط |

## 6. الخصوصية والاحتفاظ

البيانات الشخصية (الاسم، البريد، الهاتف) تُخزن في قاعدة البيانات فقط، ولا تُستخدم في أي بيانات تجريبية. سجل التدقيق يُحتفظ به 5 سنوات على الأقل (REC، NFR-025). النسخ الاحتياطي يومي بحفظ 14 يومًا (NFR-030).
