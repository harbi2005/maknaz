## 1. نموذج التهديد المختصر

| الأصل | التهديد | الضابط |
|---|---|---|
| بيانات الجهات وعروضها وأسعارها | وصول جهة لبيانات أخرى | فحص الملكية على الخادم، `404` للمورد غير المملوك (SEC-01, SEC-02) |
| الأسعار المتفق عليها | تلاعب العميل بالمبالغ | الأسعار من اللقطات والحساب الخادمي فقط؛ حقول المبالغ من العميل مرفوضة (SEC-06, SEC-07) |
| المخزون | البيع الزائد بالتزامن | تحديث ذري مشروط + قيد CHECK (NFR-019) |
| الدفع المحاكى | الدفع المكرر | Idempotency-Key + فهرس فريد جزئي (NFR-020) |
| تمديد الشحن | تمديد من غير المنجم | RBAC + الطرفية (SEC-09, SEC-10) |
| وثائق المختبر | تنزيل غير مصرح | إتاحات + روابط موقعة ≤ 5 دقائق + تدقيق (SEC-12, SEC-13) |
| الفواتير | تنزيل فاتورة صفقة أخرى | فحص الطرفية (SEC-14) |
| الصلاحيات | رفع الامتيازات | لا تعديل للدور إلا لـ OWNER؛ `/admin/*` للإدارة فقط (SEC-04, SEC-05) |
| الحسابات | تخمين كلمات المرور | Argon2id/bcrypt، حد معدل، رسائل عامة |
| سجل التدقيق | التلاعب بالأثر | append-only؛ مستخدم قاعدة البيانات بلا UPDATE/DELETE عليه |
| الملفات المرفوعة | ملفات ضارة | فحص MIME الفعلي، الأنواع PDF/JPG/PNG، حد 20MB |
| المعرفات | التعداد | UUIDv7 في كل المسارات (SEC-16) |

## 2. المتطلبات

| ID | المتطلب | المصدر |
|---|---|---|
| SR-01 | المصادقة إلزامية لكل نقطة عدا التسجيل والدخول والصحة | NFR-001 |
| SR-02 | التفويض بثلاث طبقات (الدور، الملكية، الحالة) على الخادم في كل نقطة | NFR-002 |
| SR-03 | تجزئة كلمات المرور Argon2id أو bcrypt (cost ≥ 12)؛ الحد الأدنى 10 أحرف | NFR-003 |
| SR-04 | HTTPS وHSTS، وملفات الجلسة `HttpOnly; Secure; SameSite=Lax`، وحماية CSRF | NFR-004 |
| SR-05 | حد معدل للدخول والكتابة | NFR-005 |
| SR-06 | روابط الملفات موقعة ≤ 5 دقائق والحاوية خاصة | NFR-006 |
| SR-07 | `404` لموارد الجهات الأخرى | NFR-007 |
| SR-08 | بيانات التواصل والإحداثيات الدقيقة للجهات النشطة فقط | NFR-008 |
| SR-09 | أسعار العروض والجولات لطرفيها والإدارة فقط؛ عروض النقل المنافسة للمصنع صاحب الصفقة فقط | NFR-009, NFR-010 |
| SR-10 | التحقق من الملفات بالمحتوى لا بالامتداد | NFR-044 |
| SR-11 | `Idempotency-Key` للإجراءات الحرجة | NFR-045 |
| SR-12 | رؤوس أمان: CSP، `X-Content-Type-Options`، `Referrer-Policy` | ARCHITECTURE §10 |
| SR-13 | لا أسرار في المستودع؛ الإعدادات عبر متغيرات البيئة (`.env.example` بلا قيم حقيقية) | — |
| SR-14 | السجلات لا تتضمن كلمات مرور أو رموز جلسة أو محتوى وثائق | NFR-034 |
| SR-15 | كل وصول لوثيقة غير عامة وكل إجراء إداري يُدقق | FR-035, FR-147 |
| SR-16 | فحص التبعيات دوريًا (Dependabot أو ما يماثله) بعد اعتماد التقنيات | REC |

## 3. الخصوصية

- جمع الحد الأدنى: الاسم، البريد، الهاتف، بيانات الجهة.
- لا بيانات شخصية في البيانات التجريبية أو الاختبارات أو السجلات.
- حذف الحساب يزيل البيانات الشخصية ويُبقي سجلات الصفقات مجهولة الفاعل (تصميم لاحق، OPEN).
