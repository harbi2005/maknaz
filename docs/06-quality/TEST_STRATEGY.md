## 1. الأهداف والأولويات

الأولوية القصوى منع: **البيع الزائد** · **التعديلات غير المصرح بها** · **الدفع المكرر** · **الفواتير المكررة** · **الاسترداد الخاطئ** · **انتقالات الشحنة غير الصالحة** · **تسعير النقل الخاطئ** · **تغير الأسعار المؤكدة**.

| المستوى | الأداة المقترحة | التغطية المستهدفة | يعمل في |
|---|---|---|---|
| Unit | pytest | ≥ 80% لوحدات pricing، آلات الحالة، المهل (NFR-026) | كل commit |
| Integration (خدمات + قاعدة بيانات حقيقية) | pytest + PostgreSQL في حاوية | كل خدمة انتقال | كل commit |
| API | pytest + DRF APIClient | كل نقطة: موجب + تفويض + حالة | كل commit |
| Authorization | اختبارات مولدة من [RBAC_MATRIX.md](../03-architecture/RBAC_MATRIX.md) | 100% من الصفوف (NFR-002) | كل commit |
| DB constraints | إدراج مباشر يتجاوز الخدمات | كل CHECK/UNIQUE حرج | كل commit |
| Concurrency | خيوط/عمليات متوازية على PostgreSQL حقيقي | السيناريوهات §4.2 | قبل الدمج |
| E2E | Playwright (عربي RTL) | الرحلات §5 | يوميًا + قبل العرض |
| يدوي/استكشافي | قائمة تحقق | الواجهة والعربية والتجاوب | قبل العرض |

**بيئة الاختبار:** PostgreSQL فعلي (لا SQLite) لأن القيود الجزئية والأقفال جزء من الصحة. ساعة مُتحكم بها (`freezegun` أو حقن `clock`) لكل اختبارات المهل.

## 4. سيناريوهات خاصة

### 4.1 الدقة والمصداقية
- TS-145: لا تظهر عبارات «موثّق من المنصة»، «ذكاء اصطناعي»، «مسافة القيادة» لمسافة مباشرة في أي قالب (فحص نصي آلي للقوالب والترجمات).
- TS-146: الأرقام المرجعية والمعادلات لا تنعكس في RTL (لقطة شاشة).

### 4.2 التزامن (ملخص)
TS-049، TS-051، TS-052، TS-081، TS-093، TS-099، TS-136 — تُشغّل بـ `ThreadPoolExecutor` أو عمليات متعددة على PostgreSQL حقيقي، مع حاجز بدء متزامن (`Barrier`)، وتُكرر 20 مرة لاكتشاف التقلب.
