# تعريف الإنجاز (Definition of Done)

[← فهرس الوثائق](../README.md)

> المرجع المختصر في [TEAM_RESPONSIBILITIES §10](TEAM_RESPONSIBILITIES.md#10-تعريف-الإنجاز-definition-of-done)؛ هذا الملف يفصّله حسب نوع العمل. Issue لا يُغلق ولا PR يُدمج قبل تحقق البنود المنطبقة.

## 1. لكل مهمة

- [ ] معايير القبول المذكورة في Issue أو في وثيقة المهمة متحققة
- [ ] المخرج في مكانه بالاسم والصيغة المتفق عليهما
- [ ] مرتبط بالمعرفات المرجعية (FR/BR/UC/SCR/TS/AC)
- [ ] روجع من عضو آخر وفق [CODE_REVIEW_GUIDELINES](CODE_REVIEW_GUIDELINES.md)
- [ ] لا ادعاء غير مدعوم، وكل رقم حقيقي له مصدر وتاريخ
- [ ] أي غموض مسجل في [OPEN_DECISIONS](../08-planning/OPEN_DECISIONS.md) أو Issue بوسم `decision-needed`
- [ ] فحص الوثائق في CI ناجح

## 2. الكود (SE)

- [ ] اختبارات وحدة وتكامل للمنطق الجديد، ناجحة على PostgreSQL
- [ ] حالات حدية من [TEST_STRATEGY](../06-quality/TEST_STRATEGY.md) مغطاة إن كانت مرتبطة
- [ ] الترحيلات قابلة للتطبيق على قاعدة نظيفة
- [ ] لا أسرار، ولا `float` للمال، ولا ثوابت مهل مضمنة
- [ ] رسائل الأخطاء ورموزها مطابقة لمواصفة API
- [ ] لا عيوب S1/S2 مفتوحة مرتبطة
- [ ] `CHANGELOG.md` محدث إن كان التغيير مرئيًا للمستخدم

## 3. التصميم (UX)

- [ ] الحالات الأربع: محمل، فارغ، خطأ، نجاح
- [ ] RTL ومتجاوب (جوال/لوحي/مكتبي)
- [ ] النصوص العربية النهائية، وأسماء الحالات مطابقة للوثائق
- [ ] وسوم المحاكاة والتحقق والمسافة المباشرة حيث يلزم
- [ ] مبني من مكونات نظام التصميم والتوكنز
- [ ] ملف التسليم للمطور محدث

## 4. البيانات (DA)

- [ ] مطابقة لقالب `data/templates/` ووحداته (طن، هللة، كم، UTC)
- [ ] علم `is_demo` لكل سجل، ولا أسماء شركات حقيقية في العرض التجريبي
- [ ] تقرير جودة: صفوف ناقصة، مكررة، خارج النطاق
- [ ] الحالات المرجعية للتسعير محسوبة يدويًا ومطابقة للصيغ

## 5. الأعمال (BD)

- [ ] كل رقم موسوم «رسمي» بمصدره أو «افتراض»
- [ ] نتائج المقابلات موسومة «أولية» وتذكر حجم العينة
- [ ] لا ذكر لعملاء أو شراكات أو اتفاقيات غير موثقة كتابيًا

## 6. الاختبار (QA)

- [ ] كل حالة: المعرف، المرجع، الخطوات، البيانات، المتوقع، الفعلي، النتيجة
- [ ] العيوب بخطوات إعادة إنتاج، الشدة، `request_id`
- [ ] مصفوفة التتبع محدثة

## 7. الوثائق

- [ ] مكتوبة بالعربية مع المصطلحات التقنية الإنجليزية
- [ ] لا مواعيد أو تقديرات زمنية
- [ ] الرابط إلى الفهرس في رأس الملف، ومدرجة في [docs/README.md](../README.md)
