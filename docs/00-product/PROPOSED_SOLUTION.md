# الحل المقترح وطريقة العمل

[← فهرس الوثائق](../README.md)

> **مستوى المعلومة:** متطلبات منتج معتمدة (APPROVED) وتوصيات هندسية (REC) كما في [SRS](../02-requirements/MAKNAZ_SRS.md).

## 1. الحل

سوق رقمي متخصص يربط المنجم والمصنع وشركة النقل، ويدير الصفقة من العرض إلى الاستلام في مسار واحد موثق.

## 2. رحلة الصفقة

```mermaid
flowchart RL
    A["المنجم ينشر المادة<br/>ببيانات موسومة"] --> B["المصنع يبحث<br/>ويقدم عرض شراء"]
    B --> C{"رد المنجم"}
    C -- "عرض مقابل" --> D["المصنع يقبل أو يرفض"]
    C -- "قبول" --> E["اتفاق تجاري مبدئي<br/>وحجز الكمية"]
    D -- "قبول" --> E
    E --> F["الناقلون المؤهلون<br/>يقدمون عروضًا ملزمة"]
    F --> G["المصنع يختار عرضًا<br/>= تأكيد ثلاثي"]
    G --> H["فاتورة ودفع<br/>(محاكاة)"]
    H --> I["جدولة الاستلام<br/>والتجهيز"]
    I --> J["نقل وتسليم"]
    J --> K["تأكيد الاستلام<br/>وإغلاق الصفقة"]
```

| المرحلة | ما يحدث | القاعدة الحاكمة |
|---|---|---|
| العرض | المنجم يسجل المادة والكمية والسعر والموقع والمواصفات بوسومها والوثائق | BR-010–018 |
| التفاوض | عرض المصنع، عرض مقابل واحد من المنجم، قبول أو رفض | BR-020–026 |
| الاتفاق المبدئي | الحجز الذري للكمية وإنشاء الصفقة بمهلة 24 ساعة للناقل | BR-027–030 |
| النقل | مطابقة الناقلين بالأهلية والمسافة، وعروض ملزمة من قواعد تسعيرهم | BR-031–035 |
| التأكيد الثلاثي | اختيار المصنع للعرض يصدر الفاتورة المحاكاة ويبدأ مهلة الدفع 24 ساعة | BR-036–040 |
| الدفع | دفع محاكى واحد بعد التأكيد الثلاثي فقط | BR-041–045 |
| الشحن | جاهزية، استلام، نقل، تسليم، تأكيد الاستلام | BR-050–057 |
| الاستثناءات | تمديد حصري للمنجم، إعادة تأكيد الناقل، إعادة الإسناد، إلغاء تلقائي واسترجاع محاكٍ | BR-060–078 |

## 3. ما تقوم به المنصة

- عرض المخلفات والمواد الثانوية ببياناتها وكمياتها وأسعارها ومواقعها.
- البحث والتصفية والمقارنة.
- إدارة عروض الشراء والعروض المقابلة.
- حجز الكمية ذريًا عند الاتفاق ومنع البيع الزائد.
- مطابقة الناقلين حسب صنف الحمولة والسعة ومناطق الخدمة والقرب من المنجم.
- حساب عروض النقل من قواعد كل ناقل وحفظ لقطة ثابتة للسعر.
- عرض التكلفة الكاملة للوصول قبل التأكيد.
- فاتورة ودفع واسترجاع **محاكاة** بوسم ظاهر.
- جدولة الشحن، التمديد، إعادة التأكيد، الإلغاء التلقائي، الإشعارات، سجل التدقيق.

## 4. حدود الحل

| الحد | السبب |
|---|---|
| لا حكم بصلاحية المادة | القرار الفني للمشتري بناءً على البيانات والتحاليل |
| لا تحليل آلي ولا ذكاء اصطناعي | التحدي الأول نقص البيانات المنظمة؛ أي تحليل لاحق يتطلب بيانات فعلية كافية |
| لا تحديد لأسعار النقل | كل ناقل يسعّر خدماته باستقلال |
| لا ضمان لإعادة الاستخدام أو الأثر البيئي | يُقاس فعليًا بعد التشغيل |
| لا أموال حقيقية في النسخة الأولى | الدفع والفواتير والاسترجاع محاكاة |
| لا منح لتراخيص النقل | التراخيص يصرّح بها أصحابها، والإدارة تراجعها شكليًا |
