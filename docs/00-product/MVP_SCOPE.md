# نطاق النسخة الأولى (MVP)

[← فهرس الوثائق](../README.md)

> **مستوى المعلومة:** متطلبات معتمدة وتوصيات هندسية من [SRS §3](../02-requirements/MAKNAZ_SRS.md#3-النطاق) و[MVP_ROADMAP.md](../08-planning/MVP_ROADMAP.md#2-تصنيف-النطاق-moscow).

## 1. داخل النطاق

| الوحدة | المحتوى | المتطلبات |
|---|---|---|
| الحسابات والجهات | تسجيل، تحقق البريد، الجهات الثلاث، العضوية، الاعتماد الإداري | FR-001–012 |
| المواقع | المناجم المتعددة، مواقع المصانع | FR-013–020 |
| المواد | العروض، المواصفات بوسوم التحقق، الوثائق بإتاحات، الكميات | FR-021–036 |
| البحث | النص، المرشحات، الترتيب بالمسافة المباشرة الموسومة | FR-037–042 |
| التفاوض | عرض الشراء، عرض مقابل واحد، القبول والرفض، الانتهاء | FR-043–055 |
| الصفقات | الحجز الذري، لقطة تجارية، نافذة التحميل | FR-056–061 |
| الناقلون | المواقع التشغيلية، مناطق الخدمة، الخدمات | FR-062–070 |
| التسعير | 4 نماذج، رسوم، حد أدنى، إصدارات غير قابلة للتعديل | FR-071–080 |
| المطابقة | الأهلية ثم نطاقات المسافة | FR-081–086 |
| التأكيد الثلاثي | عروض نقل ملزمة واختيار المصنع | FR-087–094 |
| الفوترة | فاتورة ودفع محاكى بـ Idempotency | FR-095–103 |
| الشحن | الدورة الكاملة | FR-104–113 |
| التمديد | حصري للمنجم، إعادة تأكيد، إعادة إسناد | FR-114–121 |
| المهل | الإلغاء التلقائي وفق القيم المعتمدة | FR-122–129 |
| الاسترجاع | محاكى كامل وجزئي | FR-130–134 |
| الإشعارات والإدارة والتدقيق | داخل المنصة، لوحة الإدارة الأساسية، سجل append-only | FR-135–150 |
| البيانات التجريبية | حزمة موسومة لا تتضمن شركات أو أسعارًا حقيقية | BR-091 |

## 2. القيم الزمنية المعتمدة

| القاعدة | القيمة |
|---|---|
| مهلة قبول الناقل | 24 ساعة |
| إعادة المحاولة عند عدم قبول ناقل | 24 ساعة إضافية |
| الحد الأقصى للتمديد | تمديدان |
| أقصى مدة لكل تمديد | 72 ساعة |
| مهلة الدفع المحاكى | 24 ساعة |
| مهلة السماح للشحن | ساعتان |
| الإلغاء التلقائي | مفعّل |

القيم موحدة مركزيًا في `system_policy_versions`، **دون واجهة إدارية لتعديلها** في هذه النسخة.

## 3. خارج النطاق

بوابة دفع حقيقية وفواتير ضريبية · خدمات توجيه المسارات وGPS · النقل بالسكك والبحري والدولي فعليًا (نموذج البيانات يدعمها) · واجهة تعديل السياسات · التسليم الجزئي · النزاعات والجزاءات والتقييمات · التكامل مع المختبرات · تطبيقات الجوال الأصلية · أي ذكاء اصطناعي أو تحليل آلي.
