# design-tokens

القيم المرئية الموحدة لمَكْنَز: [`tokens.json`](tokens.json) مصدرًا، و[`tokens.css`](tokens.css) متغيرات CSS جاهزة.

| الحالة | ملاحظة |
|---|---|
| **مقترحة** | الألوان تتبع قيم وثيقة التكليف وفق توصية **OD-13**؛ قيم لوحة الهوية الأصلية محفوظة في `color.brand-board` للمرجع حتى يُحسم القرار |
| المالك | UI/UX (UX-006) مع مراجعة SE |

## قواعد الاستخدام

- `mineral-gray` على الخلفيات الداكنة فقط؛ على الفاتح استخدم `mineral-gray-on-light` (تباين 4.5:1).
- النص فوق النحاسي `copper`: charcoal أو off-white، بحجم ≥ 16px عريض.
- الألوان الدلالية (نجاح/تحذير/خطر/معلومات) توصية هندسية قابلة للتعديل.
- المسافات (شبكة 4px) والانحناءات **توصية هندسية** غير واردة في وثيقة الواجهة؛ تُعتمد أو تُعدل في UX-006.
- أي تعديل يتم في `tokens.json` و`tokens.css` معًا في PR واحد.
